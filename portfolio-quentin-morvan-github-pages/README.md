# Portfolio — Quentin Morvan

Portfolio de présentation de créations web réalisées à titre démonstratif.

## Mise en ligne gratuite

1. Créez un dépôt public GitHub nommé `portfolio-quentin-morvan`.
2. Importez le **contenu** de ce dossier à la racine du dépôt, notamment `index.html`, `style.css`, `app.js` et le dossier `projets/`.
3. Dans `Settings > Pages`, sélectionnez `Deploy from a branch`, branche `main`, dossier `/(root)`, puis `Save`.
4. Votre site est accessible à `https://VOTRE-IDENTIFIANT.github.io/portfolio-quentin-morvan/`.

Ne chargez pas uniquement le fichier ZIP sur GitHub : vous devez déposer les fichiers décompressés.

Les projets présentés sont des démonstrations non officielles. Certaines images se chargent depuis des services externes. Avant publication commerciale, vérifiez les licences des visuels.
